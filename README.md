# CDF Main — aperçu des propositions A/B

Copie statique de présentation du site WordPress de la Clinique Dentaire
Familiale Main.

- `/a/` : proposition A
- `/b/` : proposition B
- `/a/en/` et `/b/en/` : versions anglaises

Cette publication sert uniquement à la validation visuelle par le client.
Les formulaires sont volontairement désactivés.

Pour reconstruire l’export depuis le site Local :

```bash
python3 export.py
```
